Set up a device (easy steps)

iPhone / iPad ›
  1. Install WireGuard from the App Store.
  2. Open Profiles & QR codes in this menu, unlock, and tap your profile.
  3. Download the file → tap it → Open in WireGuard. (Or in WireGuard tap + → Create from QR code and scan the QR.)
  4. Flip the switch on. Come back here and tap Refresh — it turns green.
Android ›
  1. Install WireGuard from the Play Store.
  2. In WireGuard tap + → Scan from QR code and scan your profile's QR here.
  3. Give it a name, then toggle it on.
Windows / Mac laptop ›
  1. Install WireGuard from wireguard.com/install.
  2. Unlock Profiles & QR codes here and Download your profile's .conf file.
  3. WireGuard → Import tunnel(s) from file → pick the .conf → Activate.
Each profile works on one device at a time. Give each person their own (APN 1–4).
